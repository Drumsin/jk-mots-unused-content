# How to contribute

This catalogue grows from community reports. Thank you for taking the time to share a finding or a correction.

## Report a finding or a correction

The easiest way is to [open an issue](https://github.com/Drumsin/jk-mots-unused-content/issues/new/choose) and pick **New finding** or **Correction**.

Please include:

- The file name (for example `s5.3do` or `03wswt1a.mat`)
- The game: JK, MotS, or both
- Whether you checked single-player, multiplayer, CTF, Kill-the-Fool, saber maps, or cutscenes
- The evidence: a short description, a quote from a file, and a screenshot if you have one
- The name you would like credited, if you want to be named

Community theories are welcome. Until a file confirms them, they are credited and labelled **Community theory (Name) — Speculative** (or **Speculative, not yet linked by any file** when no file has been found that supports or rules them out).

## Propose an edit

If you are comfortable with git, you can also open a pull request against `FINDINGS.md` (and `CHANGELOG.md` if the change belongs in the log). Keep the same plain style as the rest of the document, and point to the evidence in the pull request description.

## No GitHub account?

You can still post the same details in the Discord discussion where this project is shared. The maintainer will relay it here as an issue and credit you.

## Releases

Each frozen version (v2.1, v2.2, and so on) is published on the [Releases](https://github.com/Drumsin/jk-mots-unused-content/releases) page as a PDF and a zip of the full folder. The files in this repository always show the current text.
