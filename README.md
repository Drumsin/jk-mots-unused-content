# JK / MotS unused content findings

A catalogue of files in the retail *Star Wars Jedi Knight: Dark Forces II* (JK) and *Mysteries of the Sith* (MotS) data that the games never load, or that point at files which do not exist. Many of them are leftovers from cut levels, early tests, and earlier versions of models and scripts.

**Current version: v2.2** (November 2026)

**The best way to read this catalogue is the website:** [drumsin.github.io/jk-mots-unused-content](https://drumsin.github.io/jk-mots-unused-content/). It has a sidebar for every section, jump links to each finding, search, and a light/dark theme. A stable link looks like [Finding 34](https://drumsin.github.io/jk-mots-unused-content/g-hints-in-comments/#finding-34).

Have a new finding, a correction, or a file this catalogue should look at again? Please [open an issue](https://github.com/Drumsin/jk-mots-unused-content/issues/new/choose) and tell us about it. Screenshots and exact file names help a lot. If you don't use GitHub, you can still post in Discord and it will be relayed here.

## Other copies of the text

- **[FINDINGS.md](FINDINGS.md)** is the same document as a single file, with a clickable table of contents at the top. Useful if you want everything on one GitHub page or in a text editor.
- The [references](references/) folder holds the supporting CSVs (unreferenced-asset lists, comment extracts, cross-game checks, and more). GitHub shows each one as a searchable table. The website links each table to this folder and to a raw download.
- The website also has a [Data Files](https://drumsin.github.io/jk-mots-unused-content/data-files/) page that lists each of those files, what it contains, and view or download links.
- The [renders](renders/) folder holds the 3DO and texture images used in the document.

## How to contribute

See [CONTRIBUTING.md](CONTRIBUTING.md) for the full notes. In short:

- Open an issue for a new finding or a correction, using the templates under [Issues](https://github.com/Drumsin/jk-mots-unused-content/issues/new/choose).
- Or open a pull request if you want to propose an exact edit to the text. The pencil icon on the website opens the page in GitHub.
- Community theories are credited and labelled **Community theory (Name) — Speculative** until a file confirms them.

A [change log](CHANGELOG.md) lists what changed in each version.
